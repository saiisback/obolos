# AgentGDP Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development. User has chosen implementation with subagents; continue through review without further plan approval.

**Goal:** Deliver the approved six-stage research economy with a Next.js console, tested policy engine and real testnet adapters.

**Architecture:** A Next.js application owns run orchestration and a persistent audit log. A separate capability broker owns sensitive operations; a public Hedera x402 data service sells current repository evidence. Circle Agent Stack pays for verification on Arc.

**Tech Stack:** Next.js 16, React 19, TypeScript, Zod, Express, x402 v2 Hedera packages, viem, Circle CLI, Ledger Key Ring, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-07-agentgdp-design.md`

## Global Constraints
- No mainnet spending; no automatic credential provisioning, email OTP consumption or physical approval simulation in live mode.
- All money uses integer atomic units: 100,000,000 tinybar/HBAR and 1,000,000 micro-USDC/USDC.
- Never treat configuration as proof of successful settlement or sponsor qualification.
- Preserve user approval authority; adapters may not increase their own spending limits.
