# Speculos integration implementation plan

Goal: Run actual Ledger Sync and Ethereum applications in Speculos, verify the wallet-cli Key Ring enrollment path, and add explicitly labeled emulator approval support to Obolos.

The user approved the previously proposed Speculos → Sync → CLI transport → enrollment/encryption/decryption approach. Work stays in the user's ETHONLINE checkout. No software-wallet or mocked SDK fallback may be presented as Ledger Ring success. Existing physical-device support and spending policy remain intact. No real credentials enter an emulator experiment. Ring password provisioning remains an operator step.

1. Start local Docker, pin official Speculos image and Ledger CI app artifacts. Bind emulator endpoints only to loopback; mount only emulator application binaries, never app secrets or Circle state.
2. Start Sync and Ethereum emulators. Verify app identity through their actual APDU endpoints and observe their screens.
3. Inspect current wallet-cli transport and trustchain attestation protocol. Test actual enrollment compatibility using public test material; record external blockers without bypassing attestation or switching to a mock backend.
4. Add an explicitly selected emulator transport to the existing approval script, with tests for loopback endpoint validation, signer pin checks and exact message signature validation. Keep USB the default. Document emulator signatures as development evidence, not hardware security.
5. Provide reproducible startup and setup commands, source/image/artifact pins, and clear remaining credential or trustchain requirements. Run focused tests, full type/build verification if tracked runtime code changes, and an actual emulator signing experiment. No payment transactions are needed for this integration test.
